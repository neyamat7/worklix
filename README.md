**A modern micro-task marketplace connecting buyers and workers**

Worklix is a comprehensive platform that bridges the gap between task creators and skilled workers through an intuitive three-tier system. Buyers can easily post tasks and purchase coins via Stripe integration, while workers browse available opportunities and earn money by completing quality work. The platform features real-time notifications powered by Socket.io, ensuring seamless communication and instant updates throughout the task lifecycle. With robust admin controls, secure payment processing, and a responsive design, Worklix provides a professional environment for efficient micro-task management and earnings.

## 🌟 Features

### 👥 **Three-Tier User System**

- **🔧 Admin Panel**: Complete user management and task oversight
- **💼 Buyer Dashboard**: Post tasks, purchase coins, track progress
- **⚡ Worker Interface**: Browse tasks, submit work, earn rewards

### 💰 **Payment & Earnings**

- **Stripe Integration**: Secure coin purchases for buyers
- **Withdrawal System**: Easy money withdrawal for workers
- **Real-time Balance**: Live balance updates and transaction history

### 🔔 **Real-time Features**

- **Socket.io Notifications**: Instant updates for task status changes

### 🎨 **Modern UI/UX**

- **Responsive Design**: Mobile-first approach with TailwindCSS
- **Smooth Animations**: Framer Motion for engaging interactions
- **Dark/Light Mode**: Theme switching capability
- **Intuitive Navigation**: User-friendly interface design

## 📱 User Roles & Permissions

### 🔐 **Admin**

- ✅ Manage all users (buyers and workers)
- ✅ Oversee and moderate tasks

### 💼 **Buyer**

- ✅ Create and post tasks
- ✅ Purchase coins via Stripe
- ✅ Review worker submissions
- ✅ Manage active tasks

### ⚡ **Worker**

- ✅ Browse available tasks
- ✅ Submit completed work
- ✅ Earn coins for approved tasks
- ✅ Withdraw earnings
